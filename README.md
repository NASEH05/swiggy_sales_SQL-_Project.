# swiggy_sales_SQL-_Project.

• Data Preparation & Validation: Performed rigorous data cleaning, including null value checks, handling
empty strings, and duplicate record removal using the 'ROW_NUMBER()' function.
• Database Normalization & Schema Design: Transitioned from a flat table to a Star Schema to reduce
data redundancy. Created Dimension tables (Date, Location, Restaurant, Category, and Dish) and a central
Fact table with established primary and foreign key relationships.
• Deep Dive Analysis: Analyzed temporal trends (order patterns by month/quarter), location insights (best/
worst performing states), food performance (top-selling restaurants and dishes), and customer behavior
(segmenting customers based on spending buckets).
